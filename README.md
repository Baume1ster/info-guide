# info-guide

Тема: системы счисления

Информатика для первокурсника

Тема: Системы счисленияЦель проекта: Изучить основные системы счисления, познакомиться с их особенностями и научиться переводить числа из одной системы в другую.Автор: KalakСодержание проекта

\- README.md — описание проекта.

\- glossary.md — словарь основных терминов.

\- examples.md — примеры решения задач.

\- sources.md — использованные источники.

\- .gitignore — правила исключения временных файлов.

Как читать справочник

Сначала ознакомьтесь с README.md, затем изучите glossary.md, после этого перейдите к examples.md. Дополнительную информацию можно найти в sources.md.
